# Background Generator

A simple interactive web application that generates random background colors and displays their RGB values.

## Features
- Generate random background colors with a button click.
- Display the corresponding RGB color value.

## Built With
- HTML5
- CSS3
- Vanilla JavaScript

## Concepts Practiced
- DOM manipulation
- JavaScript event handling
- Dynamic CSS styling
- Random number generation

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/eddiestcc/Background_Changer.git
   ```
2. Open `index.html` in your browser.

No additional dependencies required.
